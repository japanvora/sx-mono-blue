# ORBIT
Outlined SVGs of the ORBIT product logo — an octagon ring (the family's angular circle) around a central star, with a satellite star sitting in the ring's gap. Text converted to paths (Montserrat Bold/Medium); no font needed.

| File | Use on | Inks |

| `orbit-lockup-endorsed-dark.svg` | dark grounds (#0B0F1E) | #F2F4F9, #7AA2FF, #DCE3FF, #9AA3B8 |
| `orbit-lockup.svg` | light; inside the product | Midnight, Electric |
| `orbit-lockup-dark.svg` | dark; inside the product | #F2F4F9, #7AA2FF, #DCE3FF |
| `orbit-mark.svg` | app icon, avatar, ≥ 24px | Midnight, Electric |
| `orbit-mark-small.svg` | favicon and anything < 24px — centre star only | Midnight, Electric |

Rules: never recolour; don't merge with the stateXchange mark or another product mark. For one-colour print, set every ink to #111111.
