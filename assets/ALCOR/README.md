# ALCOR

ALCOR's outlined marks and lockups. Montserrat Bold is converted to paths, so these files need no font loaded — use them for email, PDFs, contracts, app icons and any third-party surface. In HTML use `<SX.Logo product="alcor" />` instead.

ALCOR is a product in its own right, not a MIZAR skin: it is a parallel system that depends on MIZAR to work. Its container is MIZAR's diamond opened into two chevrons with a gap, and its star pair is MIZAR's inverted — the large star is ALCOR, the small one is the MIZAR it reads.

| File | Use |
|---|---|
| `alcor-lockup-endorsed.svg` | first-contact surfaces on light grounds — login, docs, contracts, marketing |
| `alcor-lockup-endorsed-dark.svg` | the same on dark grounds |
| `alcor-lockup.svg` | inside the product after sign-in, light ground |
| `alcor-lockup-dark.svg` | the same on dark grounds |
| `alcor-mark.svg` | mark alone — favicons at 32px+, avatars, app icons |
| `alcor-mark-small.svg` | below 24px — one star, no second |

**Rules**
- Never recolour, outline, rotate, add effects or set on a photo. Clear space: the cap height of the wordmark on every side.
- Minimum: mark 20px, lockup 120px wide, endorsed lockup 160px wide.
- Shown with stateXchange, the stateXchange logo leads and ALCOR sits at equal or smaller size. Never lock ALCOR's mark to MIZAR's or to the S.
