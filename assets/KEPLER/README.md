# KEPLER
Outlined SVGs of the KEPLER product logo — the letter K in two pieces (a Midnight stem and an Electric chevron whose point touches it), with the Sun in the K's mouth and a planet leaving it: Kepler's orbit, open on one side. Text converted to paths (Montserrat Bold/Medium); no font needed.
