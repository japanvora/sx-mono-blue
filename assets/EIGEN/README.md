# EIGEN
Outlined SVGs of the EIGEN product logo — a square split into matrix brackets `[ ]` holding three stars that grow along the diagonal (an eigenvector: same direction, scaled by λ). Text converted to paths (Montserrat Bold/Medium); no font needed.
