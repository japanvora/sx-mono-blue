# CELESTIA
Outlined SVGs of the CELESTIA product logo — a lens container (two long flat lids meeting at points left and right) holding a large centre star and a small star outside it, upper right. Text converted to paths (Montserrat Bold/Medium); no font needed.

| File | Use on | Inks |

| `celestia-lockup-endorsed-dark.svg` | dark grounds (#0B0F1E) | #F2F4F9, #7AA2FF, #DCE3FF, #9AA3B8 |
| `celestia-lockup.svg` | light; inside the product | Midnight, Electric |
| `celestia-lockup-dark.svg` | dark; inside the product | #F2F4F9, #7AA2FF, #DCE3FF |
| `celestia-mark.svg` | app icon, avatar, >= 24px | Midnight, Electric |
| `celestia-mark-small.svg` | favicon and anything < 24px — centre star only | Midnight, Electric |

Geometry note: the approved mark is wider than the other containers, so it is drawn at 0.9 scale inside the 100-unit box and its stroke is 11.7 rather than 13. Keep it that way.

Rules: never recolour; don't merge with the stateXchange mark or another product mark. For one-colour print, set every ink to #111111.
