# Select
A native `<select>` styled to match Field, with a token-coloured chevron.

Wrap the select in `.sx-select-wrap` (it draws the chevron) inside a `.sx-field`. Use for 4–15 fixed options; fewer → radio group (Checkbox with `type="radio"`), more → a searchable input. React: `<SX.Select label="Segment" options={["NSE F&O","MCX commodities"]} />`.
