# Checkbox
Native checkbox or radio with its label, tinted with `accent` via `accent-color`.

`<label class="sx-check"><input type="checkbox"> Label</label>` — the whole label is the hit area. Radios use the same class with `type="radio"` and a shared `name`. Use checkboxes for consent and multi-select; for an instant on/off setting use Switch. React: `<SX.Checkbox label="…" />`, `type="radio"`.
