# Badge
A compact status or category pill.

Tones: neutral (default, `surface-2`), `--accent` (category/segment), `--success` (Live, Connected), `--warning` (Paused, Degraded), `--danger` (Error, Rejected), `--outline` (versions, metadata). Add `<span class="sx-badge__dot"></span>` for live system states. One or two words, sentence case. Colour never carries meaning alone — the word does. React: `<SX.Badge tone="success" dot>Live</SX.Badge>`.
