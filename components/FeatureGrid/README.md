# FeatureGrid
A numbered grid of capabilities — mono index, title, one-sentence body — in auto-fit columns.

`div.sx-features` › `.sx-feature` › `span.sx-feature__index` (01, 02…), `h3.sx-feature__title`, `p.sx-feature__body`. 3–6 items; titles are capabilities, bodies are one factual sentence. Numbers replace icons — don't add emoji or decorative icons. React: `<SX.FeatureGrid items=[{title, body}] />`.
