# PageHeader
The opener for every page that isn't the home page: breadcrumbs, eyebrow, H1, lede and optional meta line, closed by a hairline.

`header.sx-page-head` › `.sx-container` › Breadcrumbs, `p.sx-page-head__eyebrow`, `h1.sx-page-head__title`, `p.sx-page-head__lede`, `p.sx-page-head__meta`. One H1 per page. Use the meta line for "Last updated" on legal pages. The home page uses Hero instead. React: `<SX.PageHeader title lede eyebrow meta breadcrumbs />`.
