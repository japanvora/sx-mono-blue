# Section
The page band: vertical rhythm plus the centred 1200px container. Every block on a marketing page sits in one.

`section.sx-section` › `.sx-container` › content. Variants: `--alt` (surface fill, for alternating bands), `--tight` (space-7 instead of space-8), `--edge` (hairline top border). Alternate at most every other band — three tinted bands in a row flattens the page. React: `<SX.Section variant="alt">…</SX.Section>`.
