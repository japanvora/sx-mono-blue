# SectionHeader
The eyebrow + heading + lede block that opens each page section.

`div.sx-section-head` (add `--center` for centred sections) › `__eyebrow`, `h2.__title`, `__lede`. Max width 720px, `space-7` below. Heading states a benefit or a fact, ≤ 10 words. React: `<SX.SectionHeader eyebrow title lede align="center" />`.
